# 能量单元网格（energy_unit.stl）

来源：机械组提供的 `能量单元及交互区域.STL`（2026-11-12 加入）。
二进制 STL，7040 个三角面，坐标单位为**毫米**。

## 实测几何（mm）

- 包围盒：95.0 (x) × 150.0 (y) × 94.93 (z)，长轴 = **+y**
- 轴心 (x, z) = (47.5, 47.47)，y ∈ [0, 150]
- 3 个独立闭合壳：主体 + 两个内部环
  - 主体：6384 面，占满全包围盒
  - 内部环 A：y ∈ [125, 145]，外径 70 / 内径 54
  - 内部环 B：y ∈ [10, 20]，外径 70 / 内径 54
- 中部管外径 **65**（r = 32.5）—— 与旧占位圆柱 `hollow_cylinder_r = 0.0325` 一致
- 两端法兰：y = 0 端外径 **80**；y = 150 端外径 **95**
- 内孔直径 **39.8**（r = 19.9），孔深约 105（内部端板在 y ≈ 105–110）
- y = 0 端开口；y = 150 端封闭，端面有三爪驱动槽

## 用前必须做的归一化

CAD 原点在包围盒角上，不能直接当物体坐标系。若要沿用现有抓取/放置数学
（物体坐标系 = 单元几何中心、轴向 +z、总长 0.15），需要：

1. 平移 (-47.5, -75.0, -47.47) mm → 原点挪到几何中心、轴心
2. 绕 x 轴 +90°（y → z）→ 轴向与旧圆柱的 +z 一致
3. 缩放 0.001 → 毫米转米

这三步可以烤进新网格，也可以留在 URDF/MJCF 的 `<origin>` 和 `scale` 里。

## 消费端路径

- MuJoCo：顶层 `<compiler meshdir="meshes">`，引用 `energy_unit/energy_unit.stl`
- MoveIt：`package://wust_heavy_lift_description/meshes/energy_unit/energy_unit.stl`，
  `scale="0.001 0.001 0.001"`
- 安装：`meshes/` 已由 CMake 整目录安装，新增子目录后需重新
  `colcon build --symlink-install --packages-select wust_heavy_lift_description`

## 注意 / 待补

- MuJoCo 的网格碰撞**取凸包**，内孔会消失；需要真实插入接触时，孔壁要另用
  基本体（环形排布的 box/cylinder）近似。
- 质量、质心、惯量待机械组提供（当前旧占位件是 0.1 kg，纯估计）。
- STL 名为「能量单元及交互区域」，机械组需确认 3 个壳体是否全部属于随机器人
  运动的单元，还是包含站体侧的配合件。
